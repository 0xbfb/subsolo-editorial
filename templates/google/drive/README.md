# Estrutura do Google Drive

O manifesto `structure.json` descreve a estrutura desejada sem criar pastas por API nesta etapa.

## Regras

- mover arquivo de pasta não altera sozinho seu status editorial;
- `observacoes_privadas`, fontes protegidas e backups nunca entram no Git;
- `10_ARQUIVO_EDITORIAL` atende organização humana;
- `90_ARQUIVO_TECNICO` preserva artefatos imutáveis e recuperação;
- ZIP publicado nunca é sobrescrito.
