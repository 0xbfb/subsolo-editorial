# Fontes de projeto

Os arquivos em `references/source-materials` são cópias preservadas dos artefatos recebidos no bootstrap. O manifesto SHA-256 permite detectar alteração acidental.

A base Jornal Concreto foi extraída em `references/jornal-concreto-html`. Ela é referência visual não executável: não é importada pelo build e não deve ser editada.
