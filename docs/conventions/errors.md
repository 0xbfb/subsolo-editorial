# Erros

Erros operacionais devem usar código estável, mensagem e ação recomendada.

Exemplo:

```text
SUBSOLO_FIXTURE_INVALID: a edição mínima não respeita o contrato bootstrap.
Ação: valide os campos id, date, status e title.
```

Não registrar segredos, tokens ou corpo editorial em mensagens técnicas.
