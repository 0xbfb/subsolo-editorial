# Known issues — 1.0.0-pre

## Bloqueadores

### PRE-001 — lockfile ausente

- Severidade: bloqueadora.
- Impacto: instalação não é reproduzível e a árvore transitiva não pode ser auditada.
- Evidência: `reports/prompt-20/release-verification.json`.
- Encerramento: instalação limpa com pnpm 11.15.x, commit do lockfile e auditoria arquivada.

### PRE-002 — build Astro/Pagefind não executado

- Severidade: bloqueadora.
- Impacto: `dist` e o índice Pagefind reais não foram inspecionados.
- Encerramento: `pnpm build`, `pnpm verify:dist` e scanner sobre `dist`.

### PRE-003 — E2E e acessibilidade manual pendentes

- Severidade: bloqueadora.
- Impacto: não há homologação do comportamento em navegadores suportados, leitor de tela ou navegação real por teclado.
- Encerramento: checklist de `docs/testing/user-acceptance-checklist.md` concluído e evidência em `reports/prompt-20/evidence/manual-acceptance.json`.

### PRE-004 — integrações externas não homologadas

- Severidade: bloqueadora.
- Serviços: Docker, Google Docs, Sheets, Drive, n8n, GitHub PR, Actions e Pages.
- Impacto: os contratos e simuladores passam, mas a operação real não foi demonstrada.

## Limitações não bloqueadoras da plataforma

- GitHub Pages não permite configurar arbitrariamente todos os headers HTTP pelo repositório.
- Retratos editoriais reais continuam `pending`; placeholders tipográficos são o fallback aprovado.
- Uptime Kuma local não substitui o smoke externo agendado.
